Cada produto tem no máximo uma categoria. Elas aparecem como botões no site para filtrar a busca. Renomear troca o nome em todos os produtos; se o novo nome já existir, as duas viram uma só (mesclar). Excluir deixa os produtos sem categoria. Tudo fica no Histórico. Para mudar a categoria de vários produtos de uma vez, selecione-os na aba Produtos.

Categoria Produtos Ações

Área de atuação é para quem o produto serve (Hospitais, Laboratórios, Veterinária...). Um produto pode ter várias áreas; na busca aparecem como selos com ícone e viram filtro, para montar o kit de cada cliente. Editar troca o nome ou o ícone; se o novo nome já existir, as duas viram uma só (mesclar). Excluir tira a área dos produtos. Tudo fica no Histórico. Para marcar vários produtos de uma vez, selecione-os na aba Produtos e use Editar em massa.

Tag Produtos Observação Ações

Ensine a busca do site a entender abreviações e jargões. Cada linha é um grupo: todas as palavras dele valem como a mesma coisa, nos dois sentidos. Ex.: com o grupo cx, caixa, quem busca "caixa" também encontra os produtos escritos "CX", e vice-versa. Palavras de até 4 letras só contam como palavra inteira (assim "est" não pega "estilo"). O número ao lado de cada palavra é quantos produtos a têm hoje. As mudanças valem para quem abrir ou recarregar o site.

Envie o CSV do sistema com as colunas Codigo, Descricao e Cod prd forn. Nada é gravado antes da sua confirmação.

Dica: para só categorizar ou etiquetar, use Exportar p/ categorizar (aba Produtos): o arquivo vem sem a referência, então o Excel não tem como estragá-la, e pode voltar com apenas Codigo e Categoria/Tags.

Colunas opcionais: Categoria (define a categoria do produto; célula vazia ou "-" mantém a atual) e Tags (separadas por vírgula). As tags do CSV são somente acrescentadas às que o produto já tem: a importação nunca remove tags. Sem essas colunas, categorias e tags ficam como estão.

Links do site oficial

Cada produto da busca tem dois ícones na coluna Site: a página do produto em cbsmed.com.br (com a foto em miniatura ao passar o mouse) e o PDF da ficha técnica. A sincronização lê a lista pública de produtos do site e guarda, para cada código, o endereço exato da página (o site às vezes acrescenta -2), o link da ficha e o da foto. Ela roda sozinha toda segunda-feira às 06:15; use o botão quando entrar produto novo no site e não quiser esperar. Sem sincronização, o endereço é montado pela descrição e não há ficha nem foto.

Toda edição e exclusão guarda a versão anterior. Use Restaurar para desfazer.
